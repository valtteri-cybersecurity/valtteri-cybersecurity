Project Overview

Mikä MySQL-SIEM on?

MySQL-SIEM on Pythonilla kehittämäni Linux-järjestelmien valvonta- ja tietoturva-analyysiohjelmisto.

Järjestelmä kerää tietoturvatapahtumia, lokitietoja ja järjestelmämetriikkaa. Kerätty tieto tallennetaan MySQL-tietokantaan.

Tietokantaan tallennettuja tapahtumia voidaan analysoida ja hyödyntää epäilyttävän toiminnan tunnistamiseen.

Projektissa keskityn myös ohjelmiston luotettavuuteen, testaukseen, päivitettävyyteen ja tietokannan turvalliseen käsittelyyn.

Threat Detection

Hyökkäysten tunnistaminen

MySQL-SIEM sisältää tunnistuslogiikkaa, jolla voidaan havaita tiettyjä epäilyttäviä toimintamalleja.

Esimerkiksi toistuvat epäonnistuneet SSH-kirjautumiset voivat viitata brute-force-hyökkäykseen.

Lyhyessä ajassa useisiin portteihin kohdistuvat yhteysyritykset voivat puolestaan viitata porttiskannaukseen.

Detection Examples

  • SSH Brute-Force Detection
  • Port Scan Detection
  • Source IP Analysis
  • Targeted Port Analysis
  • Security Event Statistics
Database Engineering

MySQL järjestelmän perustana

MySQL toimii MySQL-SIEMin keskeisenä tietovarastona.

Tietokantaan tallennetaan tietoturvatapahtumia, järjestelmämetriikkaa sekä kerääjien jatkuvuustietoja.

Tietokantamigraatioilla hallitaan tietokantarakenteen muutoksia järjestelmän kehittyessä.

Database Features

  • Security Event Storage
  • Collector State Tracking
  • SQL-based Analysis
  • Database Migrations
